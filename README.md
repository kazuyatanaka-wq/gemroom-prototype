# GEMROOM prototype

日本語のポケモンカード・コレクション管理／PSA損益シミュレーション試作。依存パッケージ・バックエンドなし。index.html をブラウザで開きます。GitHub Pages 等の静的ホストに設置可能ですが、このパッケージはまだ公開・pushしていません。

## 機能
カード4件の検索、棚、推し、欲しいリスト、想定値による損益試算、鑑定候補、本人入力の鑑定結果、共有PNG、JSONバックアップ。データはブラウザ内に保存。画像識別、全カード検索、相場API、オンライン共有、会員登録、実売買・鑑定申込は未実装。

## 公開版と私的プレビュー
この公開準備版は第三者のカード画像を一切含みません。中立的な自作SVGプレースホルダーのみ収録。私的レビュー用の実カード画像入りHTMLは別管理で、このリポジトリへ追加しないでください。画像URLの外部参照への変更も、利用許諾の代わりにはなりません。

ユーザーが権利を持つ写真の利用は別途確認が必要です。現行写真入力はブラウザ内の一時プレビューのみで、カードへの画像保存機能ではありません。画像を本実装する前に、対象画像・利用地域・商用利用・二次配布・サムネイル・共有機能をカバーする許諾を確認してください。

## データ
カード名・型番・収録セットは公式ページと照合。価格、鑑定枚数、想定確率、推奨候補はすべて架空のデモ値。ジェム率は特定個体のPSA10確率ではありません。鑑定・利益の保証なし。サービス導線は構想のみ。修理サービスは含みません。

## 検証
JavaScript構文、全画面描画関数、損益計算、localStorage保存、共有プレビューを単体検証。前版はChrome PC／400px表示で主要フローを確認。文言改訂版と画像非収録版は最終的な実ブラウザ再確認が必要。PNGの保存完了も再確認してください。
